How I work

Build it. Direct the agents. Prove it works.

01

Build

Hand-built, responsive, accessible front ends. Semantic HTML, modern CSS and TypeScript, from brochure sites to full web apps.

  • React, Vue, Next.js, vanilla JS
  • Node, PHP/Laravel, Python
  • Performance budgets and a11y from day one
02

Direct

I use AI coding agents the way a lead uses a strong team: clear briefs, parallel sub-agents, tight review loops, and nothing merged without evidence.

  • Claude Code, sub-agent orchestration, MCP
  • Prompt and context engineering (CLAUDE.md, specs, briefs)
  • Agent output gated by tests and review
03

Prove

Tests are the contract between what the agent says it did and what it actually did. I write suites that catch real regressions and don't flake.

  • Playwright, Selenium, Cucumber/BDD, Mocha
  • API testing (Postman, request fixtures)
  • CI on GitHub Actions, visual and a11y checks
  1. BriefA tight, testable prompt
  2. Agent buildParallel sub-agents
  3. SpecPlaywright, role-first locators
  4. CIDesktop + mobile, every push
  5. ShipOnly when it's green
