Sampling Playground

A language model hands you scores for the next word; decoding decides which one you get. Twist the knobs on two copies of the same tiny model and watch the distribution — and the sentences — change.

Toy model · 32 words · hand-written scores · not any real LLM
scores for next word→repetition penalty→÷ temperature→softmax→top-k→top-p→renormalise→sample or argmax
Both columns draw from their own generator seeded with the same number, so identical settings give identical sentences.

Temperature

Scores are divided by T before softmax. Below 1 the favourite gets more likely; above 1 the distribution flattens. At exactly 0 this page switches to greedy (always the top word).

Top-k and top-p

Top-k keeps the k most likely words. Top-p (nucleus) keeps the smallest set of top words whose probabilities add up to at least p. Whatever survives is renormalised to sum to 1.

Repetition penalty

Words already in the sentence get their score divided by the penalty if positive, multiplied if negative — a common form of the penalty introduced with the CTRL model (2019). Libraries differ in the order they apply these steps; this toy's order is shown above.

The “model” is a lookup table of scores for each word given only the previous word (a bigram table) — written by hand for this page.
