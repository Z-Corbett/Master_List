Largest Contentful Paint

As a page renders, the browser reports an LCP candidate each time an element paints that is larger than any candidate before it. The last candidate before the user first interacts (a tap, click or key press) is the page's LCP. Candidates are images, video posters, background images and blocks of text, measured by their visible area. Interaction to Next Paint

One interaction's latency runs from the input until the next frame is painted. It has three parts: input delay (the main thread is busy with something else), processing (your event handlers run: pointerdown, pointerup and click for a tap), and presentation delay (style, layout and paint, then waiting for the next frame). Frames here come every 1000/60 ms.

input delayprocessingpresentation delay

The page's INP is its worst interaction latency, except that one highest interaction is ignored for every 50 interactions, so a single outlier on a busy page doesn't set the score. Browsers report event durations rounded to 8 ms; this simulation shows exact values.

Cumulative Layout Shift

layout shift score = impact fraction × distance fraction
impact fraction = area of the union of every unstable element's before and after boxes (within the viewport) ÷ viewport area
distance fraction = the largest distance any unstable element moved ÷ the viewport's largest dimension

An element is unstable when its start position changes between frames. Growing, or appearing for the first time, doesn't count. Shifts within 500 ms of a user input are excluded (hadRecentInput). Shifts are grouped into session windows: a window keeps going while the gap between shifts is under 1 s, and for at most 5 s. CLS is the largest window's total.

Judged at the 75th percentile

A page passes a metric when at least 75% of visits are "good": the 75th percentile (p75) of the field data must be within the good threshold. This calculator uses the nearest-rank method: sort the n values, and p75 is the value at rank ⌈0.75 × n⌉. Field tools such as CrUX compute percentiles from their own aggregated data, so their figures can differ slightly.

Sources: web.dev, "Web Vitals", "Largest Contentful Paint (LCP)", "Interaction to Next Paint (INP)", "Cumulative Layout Shift (CLS)", "Defining the Core Web Vitals metrics thresholds"; the W3C Layout Instability and Largest Contentful Paint specifications. Thresholds: LCP ≤ 2.5 s good, > 4 s poor; INP ≤ 200 ms good, > 500 ms poor; CLS ≤ 0.1 good, > 0.25 poor, each at the 75th percentile. Page-speed tools don't show how Google ranks pages, and this lab doesn't claim to.
