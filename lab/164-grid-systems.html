Columns set the measure The text area is divided into equal columns separated by gutters. The column width is whatever is left once the gutters are taken out, shared equally.

Rows set the pace Cutting the depth into rows as well gives modules: small fields that images, headings and text can occupy one or several at a time.

The baseline keeps step If each module is a whole number of text lines deep, with one line as the row gap, every block of text starts on a shared baseline and lines up across columns.

Composition

 

Every shape, rule and line of type is placed on a module edge or a baseline. The poster uses whatever grid you set in section 01, so try 3 columns, then 7.

This page works in the tradition of the International Typographic Style and its grid manuals, such as Josef Müller-Brockmann's Grid Systems in Graphic Design (1981). The tools, text and posters here are original; nothing is reproduced from the book.
