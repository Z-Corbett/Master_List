What these checks can and can't tell you

    
    
      
  • They are technical hygiene checks on one HTML document, not a ranking forecast. Google has not documented most of them as ranking factors; they are about getting crawled, indexed and shown correctly.
    • 
      
  • Title and description widths are measured with canvas at 20 px and 14 px in an Arial-compatible font. Google truncates by width, and about 580–600 px is the commonly cited desktop title width, so treat the limit as approximate.
    • 
      
  • Google has said multiple h1 elements are fine, so "one h1" is a notice about clarity, not an error. Google has also said it ignores the meta keywords tag.
    • 
      
  • hreflang: each language version must list itself and all its alternates, with fully qualified URLs, and the other pages must link back. Only this page's half of that can be seen here, so run the audit on each alternate too.
    • 
      
  • robots.txt is a separate file; a noindex only works if crawlers are allowed to fetch the page and see it. The exported spec also checks the X-Robots-Tag response header, which pasted HTML can't show.
    •
