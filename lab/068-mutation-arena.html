How it runs: mutants are generated from a small tokenizer over the function's own source, so strings and regular expressions are never mutated. Each mutant is compiled and tested inside a Web Worker built from a Blob, with a 1-second watchdog: a mutant that loops forever is terminated and counted as killed by timeout, as mutation tools usually do. A mutant stops at the first failing assertion. Some mutants can be equivalent (they behave exactly like the original), and no test can kill those. None of the mutants here are equivalent, so 100 % is reachable.
