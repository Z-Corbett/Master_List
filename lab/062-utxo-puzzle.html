Virtual bytes (approximate)Fees are paid per virtual byte. This page uses a simple size model for native SegWit (P2WPKH): about 10.5 vB of overhead per transaction, ~68 vB per input and ~31 vB per output. Real sizes vary by a byte or so with signature length.
Change and dustIf your coins overshoot, the extra comes back as a change output, which costs an output now and an input later when you spend it. Change below 294 sats counts as dust under Bitcoin Core's default relay policy. Here the leftover also goes to the miner when it is worth less than the change output would cost to create and later spend.
WasteA simplified version of Bitcoin Core's waste metric: each input costs (rate − long-term rate) × 68 (spending now versus later), plus either the cost of the change (rate×31 + long-term×68) or, with no change, the excess you overpaid. Lower is better, and it can be negative when fees are cheap.
