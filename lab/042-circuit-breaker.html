How to wire

  1. Choose a gate and tap an empty slot to place it.
  2. Tap an output port (an input switch or a gate's right side), then tap an input port to connect them. Signals only flow left to right.
  3. Tap a connected input port to unplug it. Pick Remove and tap a gate to pull it.
  4. Click an input switch or a truth-table row to watch the signal move.
  5. Ctrl+Z undoes, Esc cancels a wire.
Gates follow standard Boolean logic. An unconnected gate input floats and reads as 0 in this kit.
