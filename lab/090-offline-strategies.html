How this simulation works

Latency
Cache reads take 8 ms, a network round-trip 150 ms (4 s when slow), and a request while offline fails after 30 ms.
When the cache changes
A network response is written to the cache when it arrives, not when it was requested — so a request sent before a refresh finishes still gets the old copy. Sending a request moves the clock on 0.5 s.
Staleness
“Behind” counts how many versions the server has published since the copy you got was made.
Simplifications
One URL, no HTTP caching headers, no quota or cache expiry, and no fetch retries. Real libraries differ in details such as whether a timed-out network response still updates the cache (here it does).
Everything on this page is simulated in JavaScript; no service worker is registered and no network requests are made.
