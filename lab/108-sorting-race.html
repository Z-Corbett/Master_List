Six lanes · one array · one operation per step

Sorting Race

Every lane starts from the same seeded array. On each step each algorithm gets exactly one operation, a comparison or a swap or a write, so the lane that finishes first used the fewest operations. Change the input shape and watch the order change.

  • Counting. A comparison is one test between two elements. A swap exchanges two elements and counts as two writes; a write stores one element (insertion sort shifts, merge sort copies back). A step is any one of these.
  • Bubble stops early after a pass with no swaps, and each pass ignores the sorted tail. Insertion shifts larger elements right and writes the key back only if it moved. Selection skips a swap when the minimum is already in place.
  • Merge is top-down with an auxiliary array; the copy into the auxiliary array isn't counted, and each element written back is. Quick uses the Lomuto partition with the last element as pivot and skips self-swaps, which is why it is quadratic on sorted, reversed and few-unique input. Heap builds a max-heap bottom-up with sift-down, then extracts.
