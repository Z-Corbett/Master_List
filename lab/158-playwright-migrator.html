Playwright Migrator

Cypress & Selenium → Playwright Test

Paste Cypress or Selenium WebDriver tests (JavaScript, or Python with pytest) and get idiomatic Playwright Test TypeScript. It tokenizes and reads each command chain, not find-and-replace. Selectors map to getByRole, getByTestId and friends where there's a match. Fixed sleeps become web-first assertions. Anything it can't convert is commented out and flagged, never dropped silently.

  • cy.get / contains / within / each
  • intercept + wait('@alias')
  • fixture
  • By.* locators
  • until.* waits
  • assert / chai / pytest assert
  • custom commands flagged
