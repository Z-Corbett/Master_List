Sitemap/Studio

Paste URLs, or crawl a bundled fictional shop right here in the page, and get sitemap XML that follows the sitemaps.org protocol. It escapes entities, checks every lastmod, rejects URLs from other hosts, splits at 50,000 URLs or 50 MB into a sitemap index, and warns about URLs your robots.txt blocks. Nothing is fetched: it works only on what you give it.

    The rules this checks
    
      
      
        
    • One host, one protocol. sitemaps.org: all URLs in a sitemap must use the same protocol and host as the sitemap file itself. URLs from another host (or http in an https sitemap) are rejected.
      • 
        
    • Absolute, under 2,048 characters. <loc> must be a full URL beginning with the protocol, and less than 2,048 characters.
      • 
        
    • Entity escaping. Data values must be entity-escaped: & → &amp;, ' → &apos;, " → &quot;, > → &gt;, < → &lt;. The file is UTF-8, and non-ASCII characters in URLs are percent-encoded.
      • 
        
    • lastmod in W3C Datetime. YYYY, YYYY-MM, YYYY-MM-DD, or a date with time and a time zone designator such as 2026-09-01T14:30:00+00:00 or …Z. A time without a zone is invalid. Google's documentation says it uses lastmod when it's consistently and verifiably accurate.
      • 
        
    • 50,000 URLs or 50 MB. A sitemap may hold at most 50,000 URLs and be at most 50 MB (52,428,800 bytes) uncompressed. Bigger lists are split, and a sitemap index lists the parts; an index can itself list up to 50,000 sitemaps.
      • 
        
    • priority and changefreq. They're valid in the protocol (priority 0.0–1.0), but Google's documentation says it ignores both.
      • 
        
    • Duplicates and blocked URLs. Duplicate URLs are dropped with a warning. A URL that robots.txt disallows can't be crawled, so listing it sends a mixed signal; it's flagged, not removed.
      • 
      
    
      
    Sources: the sitemaps.org protocol (sitemaps.org/protocol.html); RFC 9309, the Robots Exclusion Protocol; Google Search Central, "Build and submit a sitemap".
