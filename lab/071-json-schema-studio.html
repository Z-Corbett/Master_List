    Builds the smallest sensible document that satisfies the schema: required and listed properties, the first enum value or const, lengths and bounds respected, simple patterns solved. The result is validated again, to be sure.

    
      
    
      
    
        
    Supported keywords
    
        
    type properties required additionalProperties items minItems maxItems enum const minimum maximum exclusiveMinimum exclusiveMaximum minLength maxLength pattern oneOf anyOf allOf $ref $defs, plus boolean schemas. Anything else is ignored, and listed under the schema so you know.
    
      
    
    
    
  
    

  
    Semantics follow JSON Schema draft 2020-12 for the keywords above. pattern is an unanchored ECMA-262 regular expression with the u flag, lengths count Unicode code points, integer accepts any number with no fractional part (so 1.0 counts), items applies to every element (prefixItems is not supported), and $ref resolves JSON Pointers inside this document only (#, #/$defs/…). Error messages are this page's own wording, and paths are JSON Pointers (RFC 6901).
