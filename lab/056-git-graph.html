    Reading the map

    ● Filled station = where HEAD is. Black sign = HEAD. Coloured signs = branches · white flags = tags. Faded, dashed stations are no longer reachable from any branch, tag or HEAD — what a rebase or reset leaves behind. Commands: commit [-m "msg"], branch [-d] name [start], checkout [-b] name|hash, switch [-c] name, merge [--no-ff] name, rebase name, cherry-pick hash, reset --hard rev, tag name [rev], log, undo. Revisions accept HEAD~2, main^, ^2 and hash prefixes.
